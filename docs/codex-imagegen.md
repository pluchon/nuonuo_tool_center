# 用 Codex CLI 画高质量的系列角色图

本项目的头图、应用图标、诺诺插画都用 Codex CLI 的 `gpt-6.2-sol`（推理强度 high）调用内置 imagegen 画。下面是验证过的做法（2026-11-20 由用户提供，整理自 Gemini 的总结）。早先“每张图新开会话 + 几百字英文禁止词”的做法出图有颗粒噪点和条纹感，已经不用。

## 1. 调用方式：一个持久会话 + 链式参考图

把构图和生图提示词的编写交给 `gpt-6.2-sol (high)`，同一个系列始终用同一个会话，画风、描边、头身比才能统一。

首轮建会话，确立画风和角色底线，同时画第 1 张：

```powershell
codex exec -C C:\JavaCode\items\local_tool_manage -s workspace-write -m gpt-6.2-sol -c model_reasoning_effort="high" -i <角色标准立绘.png> - < prompt-01.txt
```

- 记下输出里的 `session id: <SESSION_ID>`，后面都接着它。
- `-s workspace-write` 让 Codex 能在出图后自己检查尺寸、透明通道，微裁到精确比例，并直接保存到指定位置。
- Windows 上直接用 PowerShell 管道传中文可能变成 GBK 乱码。用 Node 的 `spawnSync('codex', args, { input: utf8Text, encoding: 'utf8' })` 喂标准输入，或先把 `$OutputEncoding` 设成无 BOM 的 UTF-8。
- 非交互环境里一定要用 `-` 从标准输入读提示词，否则会卡在“Reading additional input from stdin”。

后续出图和返工都复用同一个会话：

```powershell
codex exec resume <SESSION_ID> -m gpt-6.2-sol -c model_reasoning_effort="high" -i <本张参考图.png> - < prompt-02.txt
```

链式参考：先画出并验收某个新造型（比如新服装三视图），再把刚定稿的图作为 `-i` 参考去画用到它的场景图，发饰、包带、鞋扣和比例几乎不会漂。

## 2. 为什么这样出图更好

1. 高推理的模型会在调用 imagegen 后自己看图验收，主动修掉耳尖贴边、配饰不一致之类的细节。
2. 清楚的自然中文意图加少量硬底线，比几百词的英文禁止词墙好：词墙会让图像模型顾此失彼，动作僵硬，还容易出噪点。
3. 同一个会话共享记忆，整个系列的描边粗细、色彩明度、留白版式天然统一。

## 3. 提示词要点

**分层交代。** 首轮一次讲清全系列不变的底线（画风、角色锚点、解剖禁忌、版式禁忌），之后每轮只写 3 到 6 行简报：规格和保存路径、一句话的画面瞬间、本张最容易翻车的一两个检查点。

**用物理遮挡和空间方位代替形容词。**
- 差：“猫尾巴画自然一点”。
- 好：“白色卷尾从后腰、百褶裙下摆后下方探出再上翘；裙摆自然遮住尾根，不能像贴纸一样贴在裙面上”。
- 左右一律双标：写清“角色自身右侧（正面看在画面左侧）”，避免背面镜像画反。

**双人同框成对写差异。** 比如姐姐高半头、及腰长发、粉花加紫缎带、尾尖圆铃；妹妹矮半头、及肩微卷加呆毛、小白花加粉缎带、尾尖星形铃。不写清就会画成双胞胎或串饰。

**外部参考图划清边界。** 借用别的图参考表情时写死：“参考图 3 只借鉴表情张力和神态，不照搬发色、瞳色或角色本身；人物必须忠于图 1”。

**文字克制。** 需要文字时只放一个简短中文标题并要求逐字核对；漫画尽量做无字默剧，靠星星眼、爱心、音符和肢体表达。README 头图、图标不放字。

**透明底与验收闭环。**
- 透明底写清：`真透明底 RGBA PNG，四周留足透明边距，不要假棋盘格、白底、地面影、文字标签`，生成后程序检查四角 alpha 为 0。
- 每张图出来后放大到 100% 看一遍：背景渐变有没有斑块、条纹，描边有没有颗粒。不满意不要重开会话，在原会话里精准指错：“只改 X，其余保持不变”。

## 4. 模板

首轮建会话：

```text
这是《诺诺的图床》的长期系列生图会话，后续会分批生成头图、图标与插画，均由你根据简要创意自主构思构图与细节，并调用 imagegen 生成。

全会话通用底线：
1. 画风：以图 1（标准立绘）为准，图 2（三视图）核对服饰和背面。温润细紫描边（#5B4378 一带），干净的大色块平涂，阴影是边缘清晰的简洁色块，不用喷枪式渐变；无噪点、无纸纹、无碎高光。背景和人物用同一套笔触。
2. 角色锚点：[发色、瞳色、猫耳且没有人类耳朵、自身左右的发饰、尾饰]。
3. 解剖与版式：猫尾从腰后、裙摆下缘自然探出，裙摆遮住尾根；不画衣服拆解说明。

第 1 张：【标题】
- 规格：[比例 / 透明底]，保存到 `路径.png`。
- 画面：[两三句话写具体瞬间、动作和光线]。
- 文字：无。
```

续轮单张：

```text
第 N 张：【标题】
- 规格：[比例 / 透明底]，保存到 `路径.png`。
- 内容：[两三句话写动作、情绪和环境]。
- 本张重点：[一两个最容易翻车的点]。
```

同会话返工：

```text
刚才那张整体构图和画风很好，只修正下面两点后覆盖保存：
1. [具体问题和改法]；
2. [具体问题和改法]。
其余动作、配色与细节保持不变。
```

## 5. 本项目踩过的坑（2026-11-20 重画头图和图标时）

- **参考图决定画风。** 第一次附的是旧的 `assets/nono/welcome.webp`（480 像素、粗描边大头 Q 版），画出来就是粗描边。第二次只附 780 像素宽的三视图，一个人才 270 像素高，只够定服装，定不了上色方式。换成网站仓库的高清标准立绘 `standard.png`（1024×1536）加三视图 `turnaround.png` 后，线条和上色才对上。
- **文字不能和参考图打架。** “柔和”“柔光阴影”“午后阳光洒进”“柔和高光”“通透”这类光影氛围词，图像模型会画成喷枪渐变，人物身上全是渐变感。只写上色方式：“干净的大色块平涂，阴影是边缘清晰的简洁色块，不用喷枪式渐变”，场景不写阳光。
- **别替模型定死构图，也别给难画的手部动作。** 二十多行的简报（按百分比摆位置、色号、道具清单、一个姿势三个动作）效果差；“踮脚用手指捏住绳上的小木夹”手指粘连、木夹穿过手掌。动作选双手拿着一张照片这种简单的，并写清握法：“拇指压在照片正面，其余四指在背后托着”。
- **一定放大到 100% 看手。** Codex 自己会出检查图，但看的是缩小版；我们这边必须逐块放大看手、脸、皮肤、裙子和背景。
- **图标要占满画面。** 透明底图标写“主体占画面约 85%”，否则缩到 16 像素就只剩一个小点；尾巴要粗、轮廓要有毛簇，光滑的细尾巴会被看成钩子或线条。

## 6. 本项目的角色锚点

- 参考图（按顺序作为图 1、图 2 附上）：网站仓库 `C:\JavaCode\items\personal_website\nuonuo_role\character\standard.png`（标准立绘，画风和比例的主锚点）、同目录的 `turnaround.png`（三视图，核对服饰和背面）。那边的 `README.md` 和 `game-and-gallery-prompts.md` 写着角色的完整设定；本仓库的 `docs/art/nuonuo-turnaround.png` 是同一套三视图的小图备份。
- 画风：温润细紫描边（`#5B4378` 一带），干净的大色块平涂，阴影是边缘清晰的简洁色块，无噪点、无纸纹、无碎高光。旧的 `assets/nono/*.webp` 描边偏粗，不要当画风参考。
- 锚点：浅紫白及腰长发，紫色眼睛；头顶一对白毛粉内耳的猫耳，脸颊两侧由长发自然垂落，没有人类耳朵；五瓣粉色小花夹和淡紫发带都在她自身右侧（正面看在画面左侧）；白紫水手服、淡紫百褶裙、短袜、玛丽珍鞋；白色卷尾从腰后裙摆下沿探出，尾尖附近系粉色缎带，下面挂一颗玫瑰粉小圆铃铛。
- 应用图标的母题：圆角照片卡片（太阳和小山），一条毛茸茸的尾巴绕在右下角，系粉色缎带和金铃铛。
