# 诺诺助手的交互与成本约定

本文记录图库项目的设计约定，供后续实现和验收使用。

## 从图库继续对话

- 多选侧栏在两个 R-18 按钮上方增加一行，左侧为「AI」，右侧为「问诺诺」。点击后打开助手，将所选图片追加到已有草稿，聚焦输入框，由用户发送。
- 聊天中的结果卡片可直接拖入输入框，双击可查看大图。图库多选和拖入卡片共用图片引用，按图片编号去重，保留顺序，每张可单独移除。资源管理器中的图片拖入助手后成为附件，发送前点击上传的附件、发送后双击消息中的图片，均可进入图片查看器。图库引用支持双击查看原图。新上传的图片在本地按内容去重，双击时读取原图；模型请求沿用预览。旧消息保留原有清晰度。
- 「第二张」对应用户所指的那组卡片及其当时的顺序。查询共同标签或解释匹配依据时读取本地记录；R-18 图片只使用允许读取的本地信息。
- 用户可追问某张图片为何命中。回答应引用当次检索的实际依据，例如已确认标签或向量匹配。单次排除只影响本轮，明确要求「以后」时才记为长期偏好。
- 检索完整执行且零命中时才报告没有找到。类目录为空时说明范围；只完成部分检索时，显示已有卡片，说明哪一步暂时不可用。
- 偏好应可查看、纠正、忘记，并区分用户明说与助手推断。用户否定某次推断后，后续做梦应识别这项纠正，避免根据同一批旧记录重新生成该偏好。

目录规划的回执记录实际处理的目录。将引用图片归档时，单独确认目标路径，保留源文件。完成状态以目标文件内容和图库索引的核验结果为准。

## 下一步指令预测

- 回复结束、助手可见、输入框为空时，短暂停顿后最多显示一条简短建议。结合当前任务、所引用的图片和用户的采纳习惯；没有合适建议时留空。
- 示例为「比较这五张图的共同标签　按 Tab 键生效」。按 Tab 只将指令正文填入草稿并保留引用，按 Enter 才发送。用户自行输入即隐藏建议，中文输入法选词时不拦截 Tab。
- 开放式讨论优先复用本轮模型附带的建议。选图或检索后，预测只读取少量普通图的名称、已确认标签、近期提问和相关偏好；一次短请求最多输出 40 个 token，同一上下文缓存一天。开启 R-18 时停用预测。
- 按会话、回复版本、图片引用和检索范围复用建议及忽略状态。切换会话、编辑或回撤、改变引用或 R-18 范围时，丢弃不再适用的建议及迟到的响应。连续忽略时降低出现频率。

交互参考 [Claude Code 官方指令预测说明](https://code.claude.com/docs/en/interactive-mode#prompt-suggestions)。

## 云端调用与本地复用

- 会话上下文预计达到窗口容量的 85% 时，自动将较早的完整对话整理成摘要。用户可输入 `/com`，按 Enter 补全淡蓝色的 `/compact` 命令，再按 Enter 执行。精简结束即更新上下文用量估算，下一次模型回复后显示实际用量。摘要按批次保存，中断后从上次保存的位置继续，聊天页面保留原文。
- 会话摘要只服务于当前对话。写入长期偏好时核对用户原话，整理时只合并同义、同类的有效记录，保留用户手动纠正的偏好。
- 做梦摘要根据有效偏好内容和实际使用的可信度判断是否重新生成。限制输出 token，持久化失败后的重试时间；临时故障逐步延长重试间隔，密钥无效时等待配置更新。
- 后台图片向量可按日限制处理张数，保存进度并优先响应用户主动操作。处理张数用于控制工作量，费用仍按实际调用统计。
- 以图搜图按实际图片内容、向量模型及预处理版本复用向量。每次重新检查分级和检索范围，返回当前有资格展示的结果。
- 新图优先沿用用户确认的分类规则。遇到现有规则未覆盖的新标签，或用户要求调整目录时，再考虑重新规划。
- 分别统计本地复用和云端前缀缓存命中。前者省去整次请求，后者按服务实际返回的用量计算。
